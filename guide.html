손목 컨트롤러 따라 하기

손목시계 하나로 PC 의 발표 슬라이드를 넘기고, 앱을 열고, 화상 회의 마이크를 끕니다. 코딩을 몰라도 이 순서대로 하면 됩니다. PC 에 따로 설치할 프로그램은 없습니다(바로 가기 키 설정만 한 번).

무엇을 만드나

시계가 PC 에 블루투스 키보드·마우스로 연결됩니다. 시계 화면을 누르거나 손목을 튕기면 그에 맞는 키(→, ←, 마침표 등)를 PC 로 보냅니다. 화면 5개(시계·발표·실행·회의·설정)를 옆으로 밀거나 BOOT 를 짧게 눌러 바꿉니다.

시계시각·날짜를 봅니다. 키를 보내지 않으니 실수로 눌러도 안전합니다. 켜면 여기서 시작합니다.
발표오른쪽 탭 = 다음, 왼쪽 탭 = 이전, 가운데 길게 = 화면 암전. 손목 튕김은 시계 설정에서 켜면 다음 장.
실행아이콘 9개(Claude·나이스·유튜브·쿨메신저·카카오톡·한글·탐색기·바탕 화면·창 닫기)를 한 번 눌러 엽니다. 들어온 직후 1.5초(쇼 진행 중이면 5초)는 '창 닫기'·'바탕 화면'이 실수 방지로 잠시 막히고 이름 자리에 '실수 방지 중'·'쇼 중 · 잠시 뒤'가 보입니다.
회의Zoom·Teams·Meet 의 마이크·카메라 끄기/켜기, 손 들기.
설정연결 모드·컴퓨터 종류·에어마우스·손목 튕김·눈 모양·테마 등 모든 설정. 키를 보내지 않습니다(설정 모드·테마).

화면 표시 읽는 법

  • 회의 타일에 ? 가 보이면 — 타일을 1.2초 길게 눌러 PC 와 표시를 맞춥니다(키는 보내지 않음, 0.6초부터 '계속 누르면 표시만'). ? = 'PC 상태 모름'.
  • '켜짐 · 추정'·'꺼짐 · 추정'이 보이면 — 시계가 보낸 키로 짐작한 표시입니다. PC 화면과 다르면 위처럼 길게 눌러 맞춥니다.
  • 다시 ? 로 돌아갔으면 — 연결이 끊긴 지 30초가 지났거나, 회의 화면을 떠난 지 600초(10분) 뒤 돌아온 경우입니다(그사이 PC 에서 바뀌었을 수 있음). 길게 눌러 다시 맞춥니다.
  • 실행 화면의 '창 닫기'·'바탕 화면'이 흐리고 '실수 방지 중'이면 — 잠깐 기다렸다 누릅니다. 실행 화면에 들어온 직후 1.5초(쇼 진행 중이면 5초, 이름 자리 '쇼 중 · 잠시 뒤')는 실수 방지로 막혀 있다가 이름이 돌아오면 눌립니다.
  • 위 상태줄 블루투스 색을 보면 — 초록 = 연결됨(키가 감), 빨강 깜빡임 = 끊김, 회색 = 연결 대기, 밝은 회색 = 연결 중, 노랑 = 다시 추가 필요(PC 에서 이 장치 제거 후 다시 추가), 어두운 회색 = 연결 모드 꺼짐.

PowerPoint·Google Slides·Zoom·Teams·Google Meet 에서 시험했습니다. Windows 기준으로 설명하고, macOS 도 대부분 동작합니다(실행 모드는 Spotlight 로 엽니다).

준비물

  • Waveshare ESP32-C6-Touch-AMOLED-2.06 시계. 배터리 포함판을 권장합니다(배터리가 없으면 USB 를 꽂아야만 켜집니다).
  • USB-C 데이터 케이블. 충전 전용 케이블은 PC 가 시계를 알아보지 못합니다.
  • Windows 10/11 PC + Chrome 또는 Edge(설치 페이지가 이 두 브라우저에서만 됩니다). 블루투스가 있어야 합니다(노트북은 대부분 있음).
  • 인터넷 연결(설치할 때만).

주의: 이름이 비슷한 ESP32-S3-Touch-AMOLED-2.06 은 다른 제품입니다. 이 펌웨어는 C6 판에만 맞습니다. 상자·판매 페이지에서 'C6' 를 꼭 확인하세요. 1단계 명령에서 Chip is ESP32-C6 이라고 나와야 합니다.

1원래 펌웨어 백업 — 꼭 먼저

새 시계에는 원래 프로그램(펌웨어)이 들어 있습니다. 설치하면 지워지므로, 되돌릴 수 있게 통째로 파일로 받아 둡니다. 한 번만 하면 됩니다(약 5분).

① Python 과 esptool 설치

  1. python.org 에서 Python 3.12 이상을 내려받아 설치합니다. 설치 첫 화면 아래의 'Add python.exe to PATH' 를 꼭 체크합니다.
  2. 시작 메뉴에서 명령 프롬프트(또는 PowerShell)를 열고 아래를 붙여 넣고 Enter. 
    pip install esptool

② 포트 번호 확인

  1. 시계를 USB 로 PC 에 연결합니다.
  2. 시작 버튼 오른쪽 클릭 → 장치 관리자 → 포트(COM & LPT) 에서 새로 생긴 COM 번호를 봅니다(예: COM7). 아래 명령의 COM7 을 내 번호로 바꿉니다.
  3. 안 보이면 케이블을 바꾸거나, BOOT(위 버튼)를 누른 채 USB 를 꽂아 다운로드 모드로 들어갑니다.

③ 칩 확인 → 백업

esptool --chip esp32c6 -p COM7 flash-id

Chip is ESP32-C6, Detected flash size: 16MB 가 보이면 맞는 시계입니다.

esptool --chip esp32c6 -p COM7 -b 460800 read-flash 0 ALL original_backup.bin

16MB 를 읽는 데 1~2분 걸립니다. 명령 창을 연 폴더(보통 C:\Users\내이름)에 original_backup.bin 이 생깁니다.

certutil -hashfile original_backup.bin SHA256

나온 긴 글자(해시)를 메모해 두면 나중에 파일이 망가지지 않았는지 확인할 수 있습니다.

백업 파일은 USB 메모리나 클라우드에 나만 볼 수 있게 보관하세요. 원래 펌웨어의 Wi-Fi 설정 같은 개인 정보가 들어 있을 수 있어 남에게 주거나 인터넷에 올리면 안 됩니다.

되돌리는 방법은 아래 문제 해결 → 원래 펌웨어로 되돌리기에 있습니다. 같은 명령은 설치 페이지 2단계에도 복사 버튼과 함께 있습니다.

2펌웨어 설치

브라우저에서 바로 설치합니다(ESP Web Tools). 시계를 USB 로 연결한 채 PC 의 Chrome 또는 Edge로 시계에 설치 페이지를 엽니다.

  1. '원래 펌웨어를 백업했습니다' 를 체크합니다(체크해야 설치 버튼이 켜집니다).
  2. 버전을 고릅니다. 맨 위가 최신입니다.
  3. 시계에 설치 → 창에서 시계 포트(COM7 등)를 고르고 연결.
  4. 설치 창에서 지우기(Erase device) 를 물으면 아래 표대로 고르고 설치를 누릅니다. 약 1분, 끝날 때까지 USB 를 뽑지 않습니다.
  5. 끝나면 시계가 다시 켜지며 시계 화면이 나옵니다.
상황지우기(Erase)결과
처음 설치선택한다원래 펌웨어의 설정 영역과 섞이지 않게 깨끗이 지우고 설치
업데이트선택하지 않는다PC 페어링·시계 설정이 그대로 남아 다시 연결할 필요 없음
원래 펌웨어로 되돌린 뒤 다시 설치선택한다처음 설치와 같음

설치 페이지의 버전 목록에 '예시' 라고만 나오면 아직 공개 버전이 올라오기 전입니다. 그때는 직접 고치기의 '개발판 설치' 방법(esptool 명령)을 쓰거나 공개 버전을 기다립니다.

3블루투스 연결(페어링)

  1. 시계는 평소 시계로만 쓰도록 블루투스가 꺼진 채 켜집니다(상태줄 '연결 꺼짐', 시계 아래 'BT OFF'). 설정 화면(시계 화면에서 오른쪽으로 한 번 밀기, 또는 화면 맨 위에서 아래로 당기기)의 연결 모드 를 켜면 PC 를 찾기 시작하고 발표 화면으로 바뀝니다. 발표 화면 가운데의 '블루투스 꺼짐 · 눌러서 연결 켜기' 카드를 눌러도 됩니다. 전원을 껐다 켜면 연결 모드는 다시 꺼지므로, 쓸 때마다 켭니다. 연결 대기 화면은 1분 동안 꺼지지 않고, 아래 도움말이 20초·30·40초에 바뀝니다(PC 블루투스 껐다 켜기 → PC 의 다른 BT 기기 잠시 끄기 → 옛 기기 제거). 그만하려면 위에서 당겨 연결 모드를 끕니다.
  2. PC: 시작 버튼을 누르고 "Bluetooth" 를 검색해 Bluetooth 설정을 연 뒤 장치 추가 → Bluetooth(시계 화면의 단계 글자와 같습니다). Windows 11 은 설정 → Bluetooth 및 장치 → 디바이스 추가 → Bluetooth, Windows 10 은 설정 → 장치 → Bluetooth 및 기타 디바이스 → Bluetooth 또는 기타 장치 추가 → Bluetooth 입니다.
  3. 목록에서 손목 컨트롤러 XXXX 를 누릅니다. XXXX 는 시계마다 다른 네 글자(예: 2D3A)라 여러 대를 구분할 수 있습니다. 비밀번호(PIN)는 묻지 않습니다.
  4. '연결됨' 이 뜨고 시계 위쪽 상태줄의 블루투스 표시가 초록으로 바뀌면 끝입니다(아래 표). 다음부터는 연결 모드만 켜면 자동으로 다시 연결됩니다.

첫 5분 — 넘김이 안 먹을 때: 연결된 직후 발표 화면에 'PC에서 PPT 창을 한 번 누르세요' 가 뜹니다(이전/다음을 두 번 보내면 곧 사라지고, 길어도 '연결됨' 표시 뒤 15초). 연결 모드를 다시 켤 때(새 수업)와 실행 타일로 다른 앱을 연 뒤 발표 화면으로 돌아왔을 때도 다시 뜹니다 — PC 앞 창이 바뀌었을 수 있기 때문입니다. 시계가 보내는 키는 PC 에서 지금 앞에 있는 창으로 갑니다. 마우스로 PowerPoint 창(또는 슬라이드 쇼 화면)을 한 번 클릭해 앞으로 가져온 뒤 시계를 누르세요.

PC 목록에 시계가 보이는데 '장치를 다시 연결해 보세요' 만 나오면 PC 쪽 블루투스 동글 문제일 가능성이 큽니다. 문제 해결 → 블루투스 동글을 보세요.

다시 연결이 안 될 때(시계에 'PC에서 이 장치 제거 후 다시 추가' 가 뜨거나 상태줄 블루투스가 노란색 — 위 표): PC 의 Bluetooth 설정(시작 → "Bluetooth" 검색) 목록에서 손목 컨트롤러 XXXX 를 골라 장치 제거(Windows 11: 오른쪽 ⋯ → 디바이스 제거, Windows 10: 장치 제거)를 누른 뒤, 위 2~3번을 다시 합니다. 이 PC 와의 열쇠가 서로 맞지 않을 때만 이 안내가 뜨고, 시계는 이 PC 기록만 지웁니다 — 다른 PC(교실·교무실)와의 연결은 그대로입니다. 멀어서 끊긴 경우에는 뜨지 않으니 가까이 가서 연결 모드를 다시 켜 보세요. 펌웨어를 지우고(Erase) 설치했을 때도 PC 에서 디바이스를 제거하고 다시 추가해야 합니다.

4시계 시간 맞추기

시계 화면의 시각은 PC 시각을 받아 맞춥니다. 처음 한 번만 하면 전원을 꺼도 유지됩니다(배터리를 뺐다면 다시).

  1. 시계를 USB 로 연결하고 설치 페이지 6번 시계 시간 맞추기 를 누릅니다.
  2. 포트를 고르고 연결하면 끝입니다. 시계가 잠깐 다시 켜질 수 있습니다(정상).

시간대는 한국(UTC+9)이 기본입니다.

5PC 바로 가기 키 만들기(실행 모드용)

실행 모드의 앱 타일(Claude·카카오톡·한글·쿨메신저)은 Ctrl+Alt+숫자 키를 보냅니다. 나이스·유튜브는 시계가 실행 창(Win+R)에 주소를 넣어 열고, 탐색기(Win+E)·바탕 화면(Win+D)·창 닫기(Alt+F4)는 Windows 기본 키라 설정이 필요 없습니다. PC 가 이 키를 받고 앱을 열도록, PC 마다 한 번 바로 가기를 만듭니다. 관리자 권한은 필요 없습니다.

  1. wrist-shortcuts.ps1 내려받기
  2. 내려받은 파일을 오른쪽 클릭 → PowerShell 에서 실행.
  3. 실행이 막히면 내려받은 폴더(보통 '다운로드')에서 PowerShell 을 열고 아래 한 줄을 실행합니다. 
    powershell -ExecutionPolicy Bypass -File .\wrist-shortcuts.ps1
  4. 앱마다 만듦 또는 건너뜀 이 나옵니다. 건너뜀 = 그 앱이 설치되어 있지 않음(설치 후 다시 실행하면 됩니다).
  5. 그래도 키가 안 먹으면 로그아웃 후 다시 로그인합니다.

스크립트는 내 시작 메뉴에 손목 컨트롤러 폴더를 만들고 바로 가기 4개를 넣을 뿐입니다(예전에 만든 크롬·파워포인트·엑셀 바로 가기는 지웁니다). 지우려면 그 폴더를 지우면 됩니다.

사용법 표

버튼(시계 오른쪽 면)

버튼누르는 법하는 일
위 BOOT짧게(1초 안에 뗌)다음 화면으로: 시계 → 발표 → 실행 → 회의 → 설정 → 시계(키는 보내지 않음). 설정 화면에서 누르면 시계로. 화면을 보지 않고도 버튼으로 모드를 돌릴 수 있음. 잠금 중에는 막힘(풀기 = BOOT 2초). 연결 대기 화면에서는 화면을 바꾸지 않고 '그만하려면 위에서 당겨 연결 끄기' 줄이 잠깐 강조됨. 1초 넘게 누르다 2초 전에 떼면 아무 일도 하지 않음(망설인 누름은 취소)
위 BOOT2초 누름잠금 켜기/끄기 — 누르고 있으면 1초부터 남은 초와 '계속 누르면 잠겨요'(잠금 중이면 '풀려요')가 보임. 잠금 중에는 발표 화면의 왼쪽·오른쪽 탭(이전·다음)만 되고, 타일·암전·밀기(모드 바꾸기)·위에서 당기기(쇼 시트·설정)·손목 튕김·에어마우스는 막힘(막힌 터치를 하면 '잠금 · BOOT 2초 = 풀기' 가 3초에 한 번 뜸). BOOT 짧게(다음 모드)도 막힘 — 발표 좌우 넘김만 됨(가운데 암전도 막힘), 풀기 = BOOT 2초. PWR(짧게 = 시계 + 눈, 3초 = 전원 끄기)는 평소대로. 켤 때 '잠금 · 발표 좌우만 동작', 풀 때 '잠금 풀림' 이 잠깐 뜸. 에어마우스를 쓰는 중이면 겨누다 잠기지 않게 3초 눌러야 잠김
아래 PWR짧게(1초 안에 뗌)바로 시계 + 눈 — 발표·실행·회의·설정 어느 화면에서든 시계로 가서 기다리지 않고 눈을 띄움(화면을 만지거나 버튼을 누를 때까지). 꺼진 화면이면 켜고 눈(조금 길게 눌렀다 떼도 됨). 잠금 중에도 됨. 화면을 끄지는 않음 — 눈 화면은 저절로 꺼지지 않고 1분 뒤 어두워지기만 함
아래 PWR두 번 짧게(0.4초 안에)시계 숫자(눈 대신) — 8초 동안 시계가 보이고, 그 뒤 아무것도 안 하면 다시 눈
아래 PWR3초 누름전원 끄기 — 누르고 있으면 1초부터 남은 초와 막대가 보이고, 3초가 되면 상어 로고가 뜨고 꺼짐(따로 확인 버튼을 누르지 않아도 됨). 설정 화면에서 눌러도 똑같이 꺼짐. 1초 넘게 누르다 3초 전에 떼면 아무것도 하지 않고 '전원은 3초' 가 잠깐 뜸.USB 가 꽂혀 있으면 꺼지지 않고 'USB 연결 · 화면만 꺼요'·'USB 빼고 PWR 3초 = 끄기' 가 4초 뜹니다. 안내 중 입력이 없으면 화면만 꺼지고 연결 모드도 꺼짐(쇼·암전도 처음으로). 화면·버튼을 만지면 그대로 계속 사용 — 정말 끄려면 USB 를 빼고 다시 3초 누름
아래 PWR4초 넘게시계가 멈췄을 때도 전원 회로가 강제로 끔(펌웨어가 이 시간을 4초로 맞춰 둠)
아래 PWR꺼진 상태에서 짧게켜기 — 상어 로고가 뜬 뒤 시계 화면. 켜질 때 연결 모드는 꺼져 있음(3단계)

동작방법하는 일

손목 튕김

  • 기본은 꺼져 있습니다. 시계 설정 화면의 손목 튕김 줄을 켜면 동작합니다(전원을 꺼도 기억). 꺼져 있으면 다음 장은 오른쪽 탭, 이전 장은 왼쪽 탭입니다.
  • 발표 화면에서만 동작합니다. 시계·실행·회의 화면이나 잠금(BOOT 2초) 중에는 무시합니다.
  • 손목을 바깥으로 튕기든 안쪽으로 튕기든 모두 '다음 장'입니다(이전 장은 왼쪽 탭).
  • 시계는 손목의 가속도(순간적으로 확 움직이는 힘)로 튕김을 알아봅니다. 세게 할 필요 없이 손목을 가볍게, 빠르게 툭 스냅하면 충분합니다. 걷기·팔 흔들기·천천히 손목 돌리기처럼 느린 움직임은 무시합니다.
  • 한 번 넘긴 뒤 0.8초 동안은 다시 넘기지 않습니다(튕긴 손목이 되돌아오는 움직임으로 두 장 넘어가지 않게).
  • 너무 잘 먹거나 안 먹으면 shared/gesture.json 의 flick.accel.peakG(기본 1.0 g)를 바꿉니다 — 올리면 더 세게 튕겨야 하고, 내리면 약한 튕김도 잡습니다. 시뮬레이터 설정 → gesture.json 의 그래프에서 점선을 끌어 보며 맞출 수 있습니다.

그 밖에

  • 시계 화면(눈)은 저절로 꺼지지 않고, 눈이 뜬 뒤 60초(1분) 지나면 30% 로 어두워지기만 합니다(충전 케이블을 꽂고 있어도 같음 — PWR 짧게는 끄지 않고 눈을 바로 띄움). 그 밖의 화면은 아무것도 하지 않으면 20초 뒤 꺼집니다(연결 대기 화면은 60초, 연결 끊김 중은 30초 이상). 시계가 스스로 켠 화면(손목 들기·배터리 알림)은 그 뒤 손대지 않으면 눈 화면이어도 20초 뒤 다시 꺼집니다. 꺼진 화면은 PWR 짧게(시계 + 눈)·화면 터치·BOOT·손목 들기로 다시 켜집니다. 눈이나 꺼진 화면에서 깨운 시계는 8초 동안 시계로 보이고, 기기가 켠 화면은 20초에 꺼집니다.
  • 손목 들면 시계로(설정 2쪽)는 기본 꺼짐입니다 — 꺼져 있으면 손목을 들어도 화면만 켜지고 보던 화면 그대로입니다. 켜면 손목을 들 때 시계 화면부터 보이는데, 연결 모드 중 발표·회의 화면이면 수업·회의를 방해하지 않게 그 화면을 그대로 둡니다(잠깐 끊겨 다시 붙는 중이어도).
  • 시계 화면에서 5초 동안 아무것도 하지 않으면 표정(눈)이 뜹니다. 눈이 떠 있는 동안은 화면이 저절로 꺼지지 않습니다(눈 화면이 대기 화면). 다른 화면에서 PWR 를 짧게 누르면 기다리지 않고 바로 시계 + 눈, 두 번 짧게 누르면 시계 숫자가 보입니다. 눈이 뜬 뒤 60초 더 지나면 배터리와 화면 보호를 위해 밝기가 30% 로 낮아집니다. 눈 화면을 터치하거나 손목을 들면 시계가 다시 보이고 밝기도 돌아옵니다(눈 화면의 첫 터치는 시계만 보여 주고 버립니다 — 그 터치로 화면이 넘어가거나 설정이 열리지 않음). 이렇게 깨운 시계는 시각을 읽을 수 있게 8초 동안 눈으로 돌아가지 않습니다. 설정 화면이거나, 연결 대기·끊김 중이거나, 배터리 10% 이하(충전 아님)이거나, 시계 시간이 맞춰지지 않았으면 눈이 뜨지 않고 평소처럼 꺼집니다.
  • 꺼진 화면을 터치하거나 BOOT 를 누르면 화면만 켜지고 누른 동작은 보내지 않습니다(주머니 속·화면을 안 보고 누른 오작동 방지 — BOOT 를 길게 눌러도 잠금·에어마우스가 되지 않음). 단 발표 화면 + PC 연결됨이면 꺼진 지 3000초(50분 — 수업 한 차시) 안에는 왼쪽·오른쪽 짧은 탭이 화면을 켜면서 바로 이전·다음 장으로 넘깁니다(가운데·위쪽·밀기·길게 누르기는 켜기만). 잠금 중에도 이 좌우 탭은 넘어갑니다(잠금은 발표 좌우만 남기므로). 시계·실행·회의 화면이나 연결 모드가 꺼져 있으면 언제나 켜기만 합니다.
  • 배터리가 20%, 10% 로 처음 내려가면 화면이 켜지며 '배터리 N% · 충전해 주세요' 알림이 3초 뜹니다(10% 는 빨강 테두리, 상태줄 배터리도 빨강). 충전하면 다시 처음부터 알립니다.
  • 에어마우스(BOOT 를 누른 채 손목을 움직여 마우스 포인터 움직이기)는 기본으로 꺼져 있습니다. 쓰려면 시계 설정에서 '에어마우스' 를 켭니다.

설정 모드·테마

설정은 다섯 번째 화면입니다. 회의 화면에서 BOOT 를 한 번 더 누르거나, 시계 화면에서 오른쪽으로 한 번 밀면 나옵니다. 위에서 당기기(발표 외 화면)와 발표 쇼 시트의 '설정' 행은 바로 가는 지름길입니다. 설정 화면에서는 키를 보내지 않습니다.

되돌리기: 마음에 들지 않으면 같은 줄을 4번 더 누릅니다(다섯 번 돌면 처음 테마). 잠금(BOOT 2초) 중에는 테마를 바꿀 수 없습니다. 시뮬레이터에서도 설정 화면의 같은 줄로 미리 볼 수 있습니다.

문제 해결

실행 화면에서 카카오톡(또는 다른 앱)이 안 열려요

5단계 PC 바로 가기 키를 그 PC 에서 했는지 확인합니다. PC 마다 한 번 해야 합니다. 스크립트에 '건너뜀' 이 나왔다면 그 앱이 설치되어 있지 않은 것입니다. 했는데도 안 되면 로그아웃 후 다시 로그인합니다.

한글 입력 상태에서 암전이 안 돼요

이 펌웨어는 암전에 B 대신 마침표 . 를 보내서 한/영 상태와 상관없이 됩니다(B 는 한글 상태에서 'ㅠ' 로 입력됨). 안 되면 ① 펌웨어가 최신인지, ② 슬라이드 쇼가 실행 중이고 그 창이 맨 앞에 있는지 확인합니다. 편집 화면에서는 마침표가 글자로 입력됩니다.

시계에 '연결 대기' 만 나오고 연결이 안 돼요
  1. 시계 설정의 연결 모드 가 켜져 있는지 봅니다(상태줄에 '연결 꺼짐' 이면 꺼진 것).
  2. PC 블루투스가 켜져 있는지 봅니다.
  3. PC 의 장치 목록에 '손목 컨트롤러 XXXX' 가 이미 있으면 디바이스 제거 후 다시 추가합니다(3단계).
  4. 다른 PC 와 이미 연결되어 있으면 그 PC 의 블루투스를 끕니다. 시계는 한 번에 PC 한 대와 연결됩니다.
  5. 30초쯤 지나 시계에 'PC의 다른 BT 기기를 잠시 끄고 다시' 가 뜨면: PC 에 붙은 블루투스 마우스·키보드를 잠시 끄고 기다립니다. 값싼 동글은 BLE 연결을 1개만 받아 다른 기기가 자리를 차지하면 시계가 들어가지 못합니다(블루투스 동글).
  6. 시계를 껐다 켭니다: USB 를 빼고 PWR 를 3초 눌러 끈 뒤(화면이 멈췄으면 4초 넘게), PWR 를 짧게 눌러 켭니다. 켠 뒤 연결 모드를 다시 켭니다.
PC 목록에 보이는데 '장치를 다시 연결해 보세요' 만 나와요(블루투스 동글)

시계는 신호를 잘 보내고 있는데, PC 의 연결 요청이 시계까지 오지 않는 경우입니다. 데스크톱에 꽂는 값싼 USB 블루투스 동글에서 자주 생깁니다.

  1. 동글 확인: 장치 관리자 → Bluetooth → 'Generic Bluetooth Radio' → 속성 → 자세히 → 하드웨어 ID 가 VID_0A12&PID_0001 이면 CSR8510 으로 표시되는 동글입니다. 이 이름을 단 '블루투스 5.0~5.3' 제품은 대부분 복제 칩(진짜 CSR8510 은 4.0)입니다.
  2. 다른 BLE 기기 끄기: 복제 칩은 BLE 연결을 한 번에 1개만 받는 경우가 많습니다. 블루투스 마우스·키보드(예: MX Master)가 그 자리를 차지하고 있으면 시계가 들어가지 못합니다. 그 기기를 끄거나, 마우스를 전용 수신기(Logi Bolt 등) 채널로 바꾼 뒤 다시 페어링합니다. (실제 사례: 마우스를 끄자 바로 연결됨)
  3. 동글을 두 개 꽂아도 소용없습니다. Windows 는 블루투스 동글을 한 번에 하나만 씁니다. 새 동글을 꽂으면 예전 동글은 뽑습니다.
  4. 근본 해결: Realtek·Intel 칩을 쓰는 정품 블루투스 5.x 동글(예: TP-Link UB500)로 바꿉니다. 마우스와 시계를 함께 쓸 수 있습니다.

드라이버를 바꾸는 것은 효과가 거의 없습니다(문제는 동글 칩). 출처를 알 수 없는 '동글 드라이버' 파일은 내려받지 않습니다.

PC 에 배터리가 늘 50% 로 나와요

배터리가 없는 판(또는 배터리 연결이 빠진 상태)이면 시계가 배터리 양을 읽지 못해 50% 로 알립니다. 배터리 포함판에서 배터리 커넥터가 제대로 꽂혀 있는지 확인합니다. USB 를 꽂고 쓰면 동작에는 문제가 없습니다.

PWR 를 짧게 눌렀는데 화면이 안 꺼지고 눈이 떠요

정상입니다. PWR 짧게는 바로 시계 + 눈입니다 — 어느 화면에서든 시계로 가서 기다리지 않고 눈을 띄웁니다. 눈 화면이 대기 화면이라 화면을 따로 끄지 않습니다(저절로 꺼지지 않고 1분 뒤 어두워지기만 함). 다른 화면은 아무것도 하지 않으면 20초 뒤 꺼집니다. 시각을 보고 싶으면 PWR 를 0.4초 안에 두 번 짧게 누릅니다(시계 숫자). 전원을 끄려면 PWR 3초입니다.

PWR 를 오래 눌렀더니 꺼졌어요 / 꺼지지 않아요

PWR 를 3초 누르면 상어 로고가 뜨고 꺼지는 것이 정상입니다(4초가 되면 전원 회로가 강제로도 끕니다). PWR 를 짧게 누르면 다시 켜집니다. 잠금은 BOOT(위 버튼) 2초입니다.

안 꺼지고 'USB 연결 · 화면만 꺼요' 가 뜨면 USB 전원이 들어오고 있는 것입니다. USB 전원이 있으면 꺼도 바로 다시 켜지므로 전원은 끄지 않고, 4초 동안 입력이 없으면 화면만 끄고 연결 모드도 끕니다(쇼·암전도 처음으로, 충전은 계속). 안내 중에 화면·버튼을 만지면 그대로 계속 사용합니다. 정말 끄려면 USB 를 빼고 다시 3초 누릅니다.

손목 튕김이 안 먹거나 너무 잘 먹어요

발표 화면인지, 잠금(BOOT 2초)이 켜져 있지 않은지 봅니다. 튕김은 짧고 빠르게(가볍게 툭) 해야 잡히고, 한 번 넘긴 뒤 0.8초 안의 튕김은 무시합니다. 감도는 저장소의 shared/gesture.json 의 flick.accel.peakG(가속도 임계값, g)를 고쳐 바꿀 수 있습니다 — 안 먹으면 낮추고, 너무 잘 먹으면 올립니다(직접 고치기).

원래 펌웨어로 되돌리고 싶어요
  1. 1단계에서 받은 original_backup.bin 이 있는 폴더에서 명령 창을 엽니다.
  2. 시계를 USB 로 연결하고(안 되면 BOOT 를 누른 채 꽂기) 아래를 실행합니다. 쓰고 나서 자동으로 검사합니다. 
    esptool --chip esp32c6 -p COM7 -b 460800 write-flash 0x0 original_backup.bin
  3. USB 를 빼고 PWR 로 껐다 켭니다. PC 의 '손목 컨트롤러 XXXX' 는 디바이스 제거합니다.

백업이 없으면 Waveshare 공식 저장소(ESP32-C6-Touch-AMOLED-2.06)의 공장 펌웨어로 같은 명령을 씁니다(파일 이름만 바꿈).

설치 페이지에서 '시계에 설치' 버튼이 회색이에요

① 백업 체크를 켰는지, ② 데스크톱 Chrome·Edge 인지(휴대폰·Safari·Firefox 는 안 됨), ③ 버전을 골랐는지 확인합니다. 버전 목록이 '예시' 뿐이면 아직 공개 버전이 없는 것입니다.

직접 고치기(개발자용)

키 배치나 판정값은 코드가 아니라 JSON 파일 두 개에 있습니다. 시뮬레이터와 시계 펌웨어가 같은 파일을 읽어서, 시뮬레이터에서 먼저 시험해 볼 수 있습니다.

저장소 구조

폴더내용
shared/keymap.json(모드·앱별 단축키, 장치 이름) · gesture.json(튕김·터치·버튼·전원 판정값) · test-vectors/(입력 → 기대 출력)
sim/이 웹앱(Vite + TypeScript): 시뮬레이터 · 설치 페이지 · 이 안내서
firmware/시계 펌웨어(ESP-IDF 5.5 + NimBLE + LVGL 9). logic/ 은 하드웨어와 무관한 판정 로직(C++)
tools/JSON → C 헤더 생성기, 글꼴 생성기
sim/public/pc-setup/PC 바로 가기 키 스크립트

고치는 순서

  1. shared/keymap.json 또는 shared/gesture.json 을 고칩니다. 시뮬레이터의 설정(톱니바퀴) 화면에서 편집하고 'JSON 내보내기' 로 받아도 됩니다.
  2. 시뮬레이터로 먼저 시험합니다. 시계 화면을 마우스로 누르면 가상 PC 와 HID 로그에 어떤 키가 갔는지 보입니다. 녹화된 손목 움직임(CSV)도 재생할 수 있습니다. 
    cd sim
npm install
npm run dev
  3. 펌웨어용 헤더를 다시 만들고 테스트합니다. 
    python tools/gen_keymap_header.py
cd sim && npm test
  4. GitHub 에 push 하면 GitHub Actions 가 테스트 → 펌웨어 빌드를 합니다(내 PC 에 ESP-IDF 가 없어도 됨). 포크한 저장소의 Actions 탭에서 ci 워크플로를 수동 실행(Run workflow)하면 개발판 .bin 이 아티팩트로 나옵니다.
  5. 개발판 설치: 아티팩트 압축을 풀고 그 폴더에서 세 파일을 나눠 씁니다(페어링 유지). 명령은 함께 든 FLASH.txt 에 있습니다. 
    esptool --chip esp32c6 -p COM7 -b 460800 write-flash 0x0 wrist-controller-버전-bootloader.bin 0x8000 wrist-controller-버전-partition-table.bin 0x10000 wrist-controller-버전-app.bin
    처음 설치라면 …-merged-full-erase.bin 을 쓰거나 먼저 esptool --chip esp32c6 -p COM7 erase-flash 를 합니다.

테스트 벡터

shared/test-vectors/*.json 은 '이런 입력이면 이런 키가 나가야 한다' 는 묶음입니다. 시뮬레이터(TypeScript, npm test)와 펌웨어 로직(C++, firmware/test)이 같은 벡터를 모두 통과해야 CI 가 통과합니다. 판정값을 바꿨는데 벡터가 깨지면, 의도한 변화인지 확인하고 벡터를 고칩니다. 벡터 생성기(sim/scripts/gen-test-vectors.mjs)는 2026-10-25 에 동결했습니다(돌리면 경고 후 멈춤). shared/test-vectors/*.json 을 직접 고친 뒤 cd sim && npm test 로 확인합니다.
