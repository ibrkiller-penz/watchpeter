## 개략도 이해도 (사용자 요청 항목)

- 허락 질문 그림(p-031): 구조는 이해됩니다. 하지만 그림 속 파일명이 "시간표.html"이고(진짜시간표.html과 다름), "항상 허락"의 뜻이 어디에도 없어서 초보가 모든 질문에 "항상 허락"을 누를 위험이 있습니다. 새 문제 1.
- 파일 형식 바꾸기 그림(p-030): 저장 창 흐름은 이해됩니다. 하지만 글자가 작고, 탐색기 설명 글이 그림 테두리와 겹칩니다. 새 문제 2.
- 터미널 여는 법 그림(p-018): 이해됩니다(검색창에 '터미널', Enter, 오른쪽 클릭 붙여넣기). 다만 Windows 전용입니다. 새 문제 3.
- 오른쪽 클릭 실행 그림(p-055): 이해됩니다. 'PowerShell에서 실행' 항목 위치가 분명하고, Windows 11 기준이라는 표시와 "더 많은 옵션 표시"도 있습니다. 하: Windows 10 메뉴 차이는 한 줄로 적어 두면 좋습니다.

- [상] p-030 | "탐색기 › 보기 › '파일 확장명'" | 파일 형식 그림의 두 번째 설명이 테두리와 겹쳐 잘리고, 글자가 본문보다 작아 "파일 형식" 드롭다운을 눌러야 하는지 안 보임. 같은 쪽 p-024 그림 아래 빨간 글도 그림 밖으로 넘침 | 설명 칸을 그림 밖으로 빼고 글자를 키움. 드롭다운에 ▼ 표시와 "여기를 눌러 고르세요" 추가. 옵션 이름("HWPX 문서 (*.hwpx)")은 실제 한글 화면으로 확인(확인 필요)
