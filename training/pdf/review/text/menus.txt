## 메뉴 지도: 어디에 무엇이 있나
  발표자도 처음에는 메뉴를 찾느라 가장 많이 헤맸습니다. 이 장의 그림은 Claude 데스크톱 앱의 실제 메뉴 이름과 배치를 그대로 옮긴 개략도입니다(2026년 11월 화면 기준, 개인 정보는 넣지 않았습니다). 이 장의 메뉴 이름은 2026년 11월 데스크톱 앱 기준이며 버전에 따라 다를 수 있습니다. 이 문장은 책에서 여기와 EP 0, 세팅 장에만 둡니다. 앱은 자주 바뀌므로 위치가 조금 달라도 메뉴 이름으로 찾으면 됩니다.
[그림]개략도 데스크톱 앱 Code 화면의 개략도. ① 모드 전환(왼쪽 위 아이콘 묶음: 채팅·Cowork·Code, 지금은 Code 선택) ② 왼쪽 아래 계정 메뉴 → 설정(Ctrl+,) ③ 입력창 아래 모델·권한 모드 ④ 오른쪽 패널: 작업 폴더, 컨텍스트, 커넥터, 결과물, 변경 사항.
### 메인 화면에서 꼭 알아 둘 네 곳
#### 모드 전환 (왼쪽 위)
이 책에서 'Code 메뉴'라고 부르는 곳이 여기입니다. 아이콘에는 Code라는 글자 대신 ‹/› 모양만 보일 수 있습니다. 왼쪽 위 아이콘 묶음에서 채팅, Cowork, Code(클로드 코드)를 오갑니다. Cowork도 이 묶음에서 고릅니다(EP 0에서 '찾아 엽니다'라고 한 곳). 선택된 모드는 테두리로 표시됩니다. 문서 업무는 Cowork, 앱 만들기는 Code로 들어갑니다.
#### 계정 메뉴 → 설정 (왼쪽 아래)
왼쪽 맨 아래 내 이름을 누르면 메뉴가 열리고, 맨 위에 설정이 있습니다. 단축키는 Ctrl+,(쉼표)입니다. 언어, 도움 받기도 여기 있습니다.
#### 입력창 아래 (가운데 아래)
메시지를 쓰는 칸 아래에 모델(예: Opus·Sonnet), 노력 정도, 권한 모드가 보입니다. 사용량을 아끼려면 여기서 모델을 바꿉니다. 모델 이름의 뜻은 아래 표를 보세요.
#### 오른쪽 패널 (Code 화면)
지금 작업 중인 폴더·저장소(환경), 대화가 얼마나 찼는지(컨텍스트 %), 연결된 커넥터, 만든 결과물, 바뀐 파일(변경 사항)을 보여 줍니다. 결과 파일은 여기서 바로 열어 볼 수 있습니다.
    모델느낌사용량
       | Haiku | 가볍고 빠름 | 적게 씀
       | Sonnet | 보통 | 보통
       | Opus | 가장 강함 | 많이 씀
  Fable은 Claude 모델 이름 중 하나로, Pro에서는 사용 크레딧으로 씁니다. 초보는 기본 선택 그대로 쓰면 됩니다.
[권한 모드는 바꾸지 마세요
    이 책은 기본 모드(파일을 고치거나 명령을 실행하기 전에 허락을 묻는 모드) 기준입니다. '자동 수락' 계열로 바꾸면 이 책의 '계획만 받기', '허락 질문 읽기' 안전장치가 작동하지 않으니 바꾸지 마세요. 폴더 안 파일을 읽기만 할 때는 묻지 않고 진행할 수 있습니다.
    Cowork의 권한 모드는 '직접 허락 / 자동 / 건너뛰기'이며, 이 책은 직접 허락 기준입니다. 영구 삭제는 어느 모드에서도 허락을 묻습니다.
  [그림]개략도 설정 창 개략도(실제 메뉴 이름). ① 사용자 지정 › 커넥터 ② 내 항목/탐색 ③ + 추가 ④ Canva가 "개인별·✓"면 연결된 것.
### 설정 창 지도
  설정 창 왼쪽 목록은 세 묶음으로 나뉩니다. 맨 위 검색 칸에 "커넥터", "사용량"처럼 이름을 치면 바로 찾아갑니다. 메뉴를 못 찾을 때 가장 빠른 방법입니다.
  아래 경로는 모두 '왼쪽 아래 내 이름(계정) → 설정'에서 시작합니다. 영어 화면이면 Settings › Customize입니다.
    하고 싶은 일찾아갈 곳이 책에서
       | 캔바·구글 드라이브 같은 서비스 연결 | 왼쪽 아래 내 이름 → 설정 › 사용자 지정 › 커넥터 (내 항목 / 탐색, + 추가) | 세팅 장, EP 13
       | 한글 플러그인 같은 묶음 설치 | 왼쪽 아래 내 이름 → 설정 › 사용자 지정 › 플러그인 | 세팅 장
       | 일하는 방법 설명서(스킬) 보기 | 왼쪽 아래 내 이름 → 설정 › 사용자 지정 › Skills | 세팅 장
       | 남은 사용량 확인 | 왼쪽 아래 내 이름 → 설정 › 환경설정 › 사용량 | Pro 장
       | 클로드 코드·Cowork 동작 바꾸기 | 왼쪽 아래 내 이름 → 설정 › 환경설정 › Claude Code / Cowork | EP 0
       | 기억해 둘 내용 관리 | 왼쪽 아래 내 이름 → 설정 › 환경설정 › 메모리 | 필요할 때
       | 내 컴퓨터 쪽 설정(확장 프로그램 등) | 왼쪽 아래 내 이름 → 설정 › 이 컴퓨터 › 시스템 / 확장 프로그램 / 개발자 | 필요할 때
  [그림]개략도 설정 › 사용량 개략도. ① 현재 세션(5시간마다 초기화) ② 주간 한도 ③ Fable 같은 모델별 막대. 팀 요금제 화면을 바탕으로 그린 개략도라 Pro 화면은 항목이 다를 수 있고, 현재 세션 막대만 보여도 정상입니다.
### 사용량 화면 읽는 법
  설정 › 사용량에는 막대가 여러 개 있습니다. 가장 중요한 것은 현재 세션 막대입니다. 5시간 단위로 다시 채워지며, 옆에 "오후 ○시에 초기화"처럼 다시 채워지는 시각이 나옵니다.
[Pro 요금제 기준으로 보면
      공식 도움말은 Pro에도 5시간 세션 한도와 주간 한도가 함께 있다고 안내합니다.
      그런데 화면에 '주간 한도' 칸이 안 보이는 선생님도 있습니다. 화면 구성은 요금제와 앱 버전에 따라 다릅니다(위 그림은 팀 요금제 화면을 바탕으로 했습니다). Pro 화면에는 '현재 세션' 막대만 보여도 정상입니다. 주간 칸이 없으면 현재 세션 막대만 보면 됩니다. 주간 한도에 가까워지면 앱이 따로 알려 줍니다.
      'Fable'(모델 이름) 같은 모델별 막대는 Pro에서는 대개 보이지 않거나 비어 있습니다. 요금 안내 기준으로 Pro에서 Fable은 사용 크레딧으로만 쓸 수 있습니다(2026년 11월 공식 안내 기준).
      '제한 초기화'는 한도를 다시 채워 주는 혜택을 받았을 때만 표시됩니다. 보통은 "현재 초기화 없음"입니다.
[메뉴를 못 찾을 때
      책과 메뉴 위치가 다름
설정 창 맨 위 검색에 메뉴 이름을 칩니다. 그래도 없으면 계정 메뉴의 도움 받기나 공식 도움말(support.claude.com)에서 이름으로 찾습니다.
      설정 창이 어디서 열리는지 모르겠음
키보드에서 Ctrl+,를 누릅니다(맥은 ⌘+,).
      커넥터를 연결했는데 대화에서 안 씀
커넥터 목록에서 상태가 ✓인지 보고, 새 대화를 열어 "캔바 커넥터로 ○○ 해 줘"처럼 이름을 넣어 말합니다.
  위치는 바뀌어도 이름은 그대로입니다. 막히면 설정 창 검색부터.
