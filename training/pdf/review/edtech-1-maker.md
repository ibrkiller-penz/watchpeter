# 에듀테크 1차 - 기술·메이커 교사 (p-102~p-120, EP 12~14)

## ① 고친 것
- p-102 (ep12): 쪽 아래 1/4이 비어 '이 장에서 쓰는 말' 설명 상자(사이트·차시 페이지·첫 화면) 추가.
- p-104 (ep12 4단계 확인하기): 'PC 크롬에서 확인 → 링크 눌러 보기 → 휴대폰·TV는 올린 뒤 주소로'로 순서를 바로잡음. 처음엔 "내 휴대폰으로 열고"라 해 놓고 뒤에서 "올린 뒤에"라 하던 모순 제거.
- p-107 (ep12): 사례 상자 아래 반쪽이 비어 '처음엔 단원 하나만 올리고 휴대폰·TV로 열어 보기' 팁 상자 추가.
- p-114 (ep14): 쪽 절반이 비어 '처음 나오는 말'(OpenSCAD·STL·슬라이서) 상자 추가.
- p-117/118 (ep14): '왜 이렇게 말하나요?' 상자가 p-117 남은 자리에 아슬아슬하게 안 들어가 p-117 아래 반쪽이 비던 문제. 해설 3줄(단위, 바닥, 지지대, 한글 글꼴)을 한 줄로 줄여 상자 높이를 약 60px 줄임(뜻 유지).
- 확인만 한 것: 한 글자 줄바꿈, 크기 섞임, 쪼개진 덩어리는 담당 쪽에서 눈에 띄는 것 없음. div·section·table 여닫이 수 일치.

## ② 편집장에게 넘길 것
- 그림 ep14 개략도(p-116 위): 코드가 '글자높이 = 1.5; ... size = 9'인데 본문·프롬프트는 글자 크기 10, 판 위로 솟는 높이 1.5, 모서리 반지름 3. 변수 이름을 '글자크기 = 10', '글자돌출 = 1.5'로 바꾸고 size를 10으로 맞추고, 프롬프트의 모서리 반지름 변수도 넣거나 '예시 개략도' 표기 유지(본문의 '글자 높이 10→12'와 이름이 어긋나 초보가 헷갈림).
- 그림 ep14 흐름도(p-114): 2번 상자 '.OpenSCAD 코드' 글자가 상자 좌우에 거의 닿음. 상자 폭을 늘리거나 글자 크기를 줄이기.
- p-109 표: 첫 열 '클로드 코드'가 두 줄로 쪼개짐. 첫 열 폭을 약간 넓히기.
- p-102·107·114·117 빈 쪽 문제가 위 보강으로 풀렸는지 재조판 뒤 확인(쪽 나뉨 규칙 때문에 보강 상자 크기에 따라 다시 밀릴 수 있음).

## ③ 남은 문제
- p-113(ep13 끝) 아래 1/3, p-108·p-120(장 끝) 아래 1/4 정도 여백은 장 끝이라 그대로 둠.
- p-107 사례 그림에 '교사용·전자칠판' 버튼이 보이고, 본문 프롬프트 5는 교사용 자료를 공개 사이트에 올리지 말라고 함. 사례(실제 입구 화면)와 안내가 다르게 읽힐 수 있음. SPEC 140행(교사용은 학생 입구에 넣지 않음)과 대조해 사실 확인 필요.
- 재조판(build)은 하지 않아 보강 상자의 실제 쪽 위치는 미확인.
