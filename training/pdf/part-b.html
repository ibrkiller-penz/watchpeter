발표자 사례: 코드 한 줄 안 쓰고 '손목 컨트롤러' 만들기

수업이나 발표 중에 교탁으로 돌아가 키보드를 누르지 않고, 손목시계로 PPT를 넘기면 어떨까요? 발표자는 이 아이디어를 클로드 코드로 만들었고, 코드는 한 줄도 직접 쓰지 않았습니다. 이 장은 그 과정을 순서대로 보여 줍니다. 여러분이 앱을 만들 때도 같은 순서를 쓰면 됩니다. 시계가 없어도 괜찮습니다. 여기서 가져갈 것은 시계가 아니라 '만드는 순서'입니다.

무엇을 만들었나

  • 손목 컨트롤러: Waveshare ESP32-C6 AMOLED 시계가 PC에 블루투스 키보드로 연결됩니다. 화면을 탭하거나 손목을 튕기면 PPT가 넘어갑니다. 오른쪽 화살표, 왼쪽 화살표, 마침표(화면 암전)를 보냅니다.
  • 실행 화면: 아이콘 9개로 Claude, 나이스, 유튜브, 쿨메신저, 카카오톡, 한글, 탐색기, 바탕 화면, 창 닫기를 엽니다.
  • 회의 화면: Zoom, Teams, Meet의 마이크, 카메라, 손 들기를 누릅니다.
  • 화면 5개: 시계, 발표, 실행, 회의, 설정. 버튼은 BOOT와 PWR 두 개입니다.
  • 함께 만든 것: 웹 시뮬레이터, 브라우저에서 USB로 설치하는 페이지, 초보용 '따라 하기' 안내서, PC 바로 가기 스크립트.

단계마다 무엇을 했고, 어떻게 말하면 되나

  1. 아이디어를 한 문단으로

    "수업 중 손목으로 PPT 넘기기, 앱 열기, 회의 마이크 끄기." 이 정도로 시작했습니다. 기술 이야기는 필요 없습니다. 불편했던 장면을 그대로 적으세요.

  2. 계획 먼저 받기

    코드를 만들기 전에 화면 배치, 버튼 동작, 설치 방법을 문서로 받습니다. 계획이 있으면 클로드가 길을 잃지 않고, 선생님도 무엇이 만들어질지 미리 알 수 있습니다.

  3. 시뮬레이터 먼저 (10월 17일)

    시계가 오기 전에도, 웹에서 시계 화면과 가상 PC, 보낸 키 기록(HID 로그)을 볼 수 있게 먼저 만들어 올렸습니다. 고칠 때마다 눌러 보고 바로 확인할 수 있습니다.

  4. 실제 시계 데이터로 기준 정하기 (10월 18일)

    손목 튕김을 실제 시계로 녹화해 CSV 파일로 받았습니다. 바깥으로 세게 6번, 안쪽으로 세게 3번, 약하게 2번, 천천히 돌리기도 했습니다. 이 파일을 클로드에게 주고 "어느 세기부터 넘김으로 볼지" 기준을 데이터로 정했더니 1.0g가 되었습니다. 오작동이 걱정되어 튕김 기능의 기본값은 '꺼짐'으로 바꿨습니다.

  5. 쓰는 사람용 안내서

    시계를 산 교사와 학생이 보고 따라 할 쉬운 한국어 안내서를 만들었습니다. 1단계는 원래 펌웨어 백업입니다. 문제가 생겨도 되돌릴 길을 먼저 만들어 두는 순서입니다.

  6. 2호기 고도화 1~5회차 (10월 24~26일)

    써 보며 불편한 점을 모아 회차별로 고쳤습니다. 화면 5개, 테마 5종, PWR 버튼 짧게 누르면 시계와 눈, 두 번 누르면 시계 숫자, 실행 타일이 PC 설정 없이 Win+R로 앱을 여는 것까지 갔습니다.

따라 만들기: '모둠 뽑기' 웹 앱

EP 6의 순서를 작은 앱으로 직접 해 봅니다. 하드웨어는 필요 없고, 컴퓨터와 크롬 브라우저만 있으면 됩니다. 결과물은 HTML 파일 하나입니다. 더블 클릭하면 열리고, 인터넷이 없어도 됩니다. 네 단계로 나누어, 한 단계가 끝날 때마다 직접 열어 확인합니다.

준비

  • 클로드 코드를 열어 둡니다. 내 컴퓨터에서 하려면 Claude 데스크톱 앱의 Code 메뉴에서 새 폴더를 고릅니다. 웹이나 휴대폰에서 하려면 claude.ai/code를 씁니다. 메뉴 이름은 버전에 따라 다를 수 있습니다. 유료 요금제(Pro 이상)가 필요합니다.
  • 작업할 빈 폴더를 하나 만듭니다. 이름은 [모둠뽑기]처럼 알아보기 쉽게 합니다.
  • 실제 학생 이름은 쓰지 않습니다. 시험용 가짜 이름으로만 합니다.

따라 하기

  1. 1단계. 계획만 받기

    아직 만들지 않습니다. 화면 구성과 기능 목록을 먼저 받아 읽고, 클로드가 하는 질문에 답합니다.

  2. 2단계. 가장 작은 판 만들기

    핵심 기능만 만듭니다. 이름 넣기, 모둠 나누기, 다시 섞기입니다. 가짜 이름 24개가 미리 들어 있어서 바로 눌러 볼 수 있습니다.

  3. 3단계. 하나씩 키우기

    기능을 한 번에 하나씩 더합니다. 이번에는 같은 모둠이 되면 안 되는 두 사람을 지정하는 기능입니다.

  4. 4단계. 여기까지 저장

    잘 되는 상태를 저장 지점(커밋)으로 남깁니다. 다음에 망가져도 여기로 돌아올 수 있습니다.

클로드: [모둠뽑기.html] 파일을 만들겠습니다. 이 폴더에 파일을 써도 될까요?

나: (읽어 보고 허락합니다)

클로드: 만들었습니다. 확인 방법입니다. 1) 파일을 더블 클릭해 엽니다. 2) '모둠 나누기'를 누르면 6개 모둠이 나옵니다. 3) '다시 섞기'를 누르면 구성이 바뀝니다.

파일을 크롬에서 여는 법

  1. 파일 찾기

    작업 폴더(내 컴퓨터에서 했다면 탐색기, 맥이면 파인더)를 열고 [모둠뽑기.html] 파일을 찾습니다.

  2. 열기

    파일을 두 번 클릭합니다. 크롬이 기본 브라우저가 아니라면, 파일을 마우스 오른쪽 버튼으로 눌러 '연결 프로그램'에서 크롬을 고릅니다. 또는 크롬 창에 파일을 끌어다 놓아도 열립니다.

  3. 웹(claude.ai/code)에서 만들었다면

    파일은 클라우드에 있어서 내 컴퓨터에서 바로 열리지 않습니다. 클로드에게 "이 파일을 내려받는 방법을 알려 줘"라고 물어보세요.

확인하세요

  • 크롬에서 화면이 열리고, 가짜 이름 24개가 보이나요?
  • '모둠 나누기'를 누르면 모둠 카드가 크게 나오나요?
  • '다시 섞기'를 누르면 구성이 바뀌나요?

3단계. 하나씩 키우기

이렇게 말하세요

잘 돼. 이제 하나만 더하자: [같은 모둠이 되면 안 되는 두 사람을 지정하는 기능].
다른 부분은 바꾸지 말고, 바꾼 내용을 짧게 알려 줘.

왜 이렇게 말하나요?

"잘 돼"
지금까지 잘 된 것을 확인해 주면, 클로드가 그 부분을 지켜야 한다고 압니다.
"하나만 더하자"
한 번에 하나만 더하면 문제가 생겨도 원인이 분명합니다.
"다른 부분은 바꾸지 말고"
고치다가 멀쩡한 것이 망가지는 일을 막습니다.
"바꾼 내용을 짧게"
무엇이 달라졌는지 알아야 확인할 곳이 정해집니다.

화면에서 일어나는 일 (예시)

클로드: 이름 두 개를 '떨어뜨릴 짝'으로 고르는 칸을 추가했습니다. 모둠을 만들 때 이 짝이 같은 모둠이면 다시 섞습니다. 다른 부분은 그대로입니다.

나: 가짜 이름 중 두 명을 짝으로 넣고 열 번 섞어 볼게.

다음 기능도 같은 방식으로 하나씩 더합니다. 예: 글자 크기 키우기, 모둠 이름 붙이기, 결과 저장하기.

확인하세요

  • 지정한 두 사람이 열 번 섞어도 같은 모둠에 안 들어가나요?
  • 이전에 되던 기능(이름 넣기, 다시 섞기)이 여전히 되나요?

4단계. 여기까지 저장

이렇게 말하세요

여기까지 잘 돼. 지금 상태를 저장 지점(커밋)으로 남겨 줘.
저장 이름은 [모둠 뽑기: 같은 모둠 금지 추가]로 해 줘.

왜 이렇게 말하나요?

"잘 돼"
잘 되는 상태만 저장 지점으로 남깁니다.
"저장 이름"
나중에 목록에서 어느 지점으로 돌아갈지 고르기 쉽습니다.

화면에서 일어나는 일 (예시)

클로드: 저장 지점을 만들겠습니다. 이 명령을 실행해도 될까요?

나: (명령을 읽어 보고 허락합니다)

클로드: 저장했습니다. 나중에 문제가 생기면 이 지점으로 되돌릴 수 있습니다.

확인하세요

  • 클로드가 저장했다고 알려 주었나요?
  • 다음 기능을 더하기 전에 이 저장을 한 번 해 둔 습관이 생겼나요?

이럴 땐

파일을 열었는데 빈 화면이에요
클로드에게 "[모둠뽑기.html]을 열었는데 빈 화면이야. 원인을 찾아 고쳐 줘"라고 말하세요.
고친 뒤로 이전 기능이 안 돼요
"마지막 저장 지점으로 되돌려 줘"라고 하세요. 그래서 4단계 저장이 중요합니다.
인원이 나누어떨어지지 않아요
1단계에서 정한 규칙(앞 모둠에 한 명씩 더하기)을 다시 말해 주세요.

작은 판을 먼저 열어 보고, 하나씩 키우고, 잘 될 때 저장합니다.

EP 8

만든 앱을 링크 하나로 동료에게

넣는 것내 앱 파일 + "한 단계씩 안내해 줘"
→
나오는 것누구나 누르면 열리는 웹 주소

처음 한 번 약 20분

동료와 나누기: GitHub Pages로 링크 하나 공유

앱을 만들었다면 동료 선생님도 쓰게 해 주고 싶습니다. 파일을 메신저로 보내면 열기 번거롭고, 고칠 때마다 다시 보내야 합니다. 웹 주소(링크) 하나로 나누면 누르기만 하면 되고, 고치면 같은 링크에서 새 버전이 보입니다.

먼저 알아 둘 말 두 가지

  • GitHub는 파일을 올려 두는 온라인 저장소입니다. 고친 기록(커밋)도 함께 남습니다.
  • GitHub Pages는 저장소에 올려 둔 웹 파일을 무료 웹 주소로 보여 주는 기능입니다.

정확한 메뉴 위치와 설정 방법은 시기에 따라 바뀔 수 있습니다. 그래서 여기서는 메뉴를 외우지 않고, 클로드에게 한 단계씩 안내받는 방식을 씁니다. 클로드 코드를 claude.ai/code(웹, 휴대폰)로 열고 GitHub 저장소를 연결해 두었다면 가장 편합니다.

준비

  • 공유할 앱 파일(예: [모둠뽑기.html])이 잘 되는 상태로 저장되어 있어야 합니다.
  • GitHub 계정이 있어야 합니다. 없다면 클로드에게 "가입 방법을 쉽게 알려 줘"라고 부탁하세요.
  • 올리기 전 개인정보 검사를 합니다. 아래 박스를 꼭 읽으세요.

공개 전 개인정보 검사 (필수)

확인하세요

  • 학생 실명, 학번, 연락처, 사진이 파일 안에 들어 있지 않은가요?
  • 테스트용 이름이 정말 가짜인가요? 실제 명단을 붙여 넣어 시험하지 않았나요?
  • 학교 내부 주소, 비밀번호, 개인 이메일이 코드나 설명에 남아 있지 않은가요?
  • 공개 저장소에 올린 것은 누구나 볼 수 있다고 생각하세요.

따라 하기

  1. 개인정보부터 검사하기

    올리기 전에 클로드에게 검사를 시킵니다. 이 단계를 건너뛰지 마세요.

  2. 안내받기

    "한 단계씩, 내가 할 일과 네가 할 일을 나눠서" 알려 달라고 합니다. 한 단계가 끝나면 "했어. 다음은?"이라고 말합니다.

  3. 링크 열어 보기

    다 되면 받은 주소를 내 휴대폰과 다른 컴퓨터에서 열어 봅니다. 처음에는 주소가 열리기까지 시간이 걸릴 수 있습니다.

  4. 동료에게 보내기

    주소만 메신저로 보냅니다. 고친 뒤에는 클로드에게 "고친 내용을 다시 올려 줘"라고 하면 같은 주소에서 새 버전이 보입니다.

1. 개인정보 검사

[모둠뽑기.html]을 인터넷에 공개해도 되는지 점검해 줘.
학생 이름, 학번, 연락처, 사진, 비밀번호, 학교 내부 정보가 들어 있는지 찾아서 목록으로 알려 줘.
아직 고치지는 말고, 찾은 것과 그 위치만 보여 줘.

2. 한 단계씩 안내받기

이 앱을 동료 선생님들이 주소(링크)만 눌러서 쓰게 하고 싶어.
GitHub Pages로 무료로 올리는 방법을 코딩 초보 기준으로 한 단계씩 안내해 줘.
내가 할 일과 네가 할 수 있는 일을 나눠서 알려 주고, 한 번에 한 단계씩만 보여 줘. 내가 "했어"라고 하면 다음 단계로 넘어가.
학생 이름 같은 개인정보가 올라가지 않게 확인해 줘.

3. 고친 뒤 다시 올리기

[모둠뽑기.html]을 고쳤어. 같은 주소에서 새 버전이 보이게 다시 올려 줘.
올리기 전에 개인정보가 없는지 한 번 더 확인해 줘.

왜 이렇게 말하나요?

"공개해도 되는지 점검해 줘"
한 번 공개하면 누구든 볼 수 있어서, 올리기 전에 먼저 확인합니다.
"아직 고치지는 말고"
무엇이 있는지 내가 먼저 눈으로 보고 결정하기 위해서입니다.
"코딩 초보 기준으로 한 단계씩"
메뉴 이름이 바뀌어도 클로드가 지금 화면에 맞게 안내합니다.
"내가 할 일과 네가 할 수 있는 일"
로그인처럼 내가 직접 해야 하는 일과, 클로드가 대신 처리하는 일을 구분합니다.
"내가 '했어'라고 하면 다음 단계"
한꺼번에 쏟아내지 않고 내 속도에 맞춥니다.

화면에서 일어나는 일 (예시)

나: (프롬프트 1을 보냅니다)

클로드: 점검했습니다. 학생 이름처럼 보이는 것은 시험용 가짜 이름 24개뿐이고, 연락처나 학번은 없습니다. 올려도 되겠습니다.

나: (프롬프트 2를 보냅니다)

클로드: 1단계입니다. 먼저 이 파일을 GitHub 저장소에 올립니다. 이 명령을 실행해도 될까요? 끝나면 "했어"라고 알려 주세요.

확인하세요

  • 개인정보 검사 결과를 직접 읽어 보았나요?
  • 받은 주소를 다른 기기에서도 열어 보았나요?
  • 링크를 받은 동료가 설명 없이도 앱을 쓸 수 있나요?

이럴 땐

주소를 눌렀는데 아직 안 열려요
올린 직후에는 시간이 걸릴 수 있습니다. 조금 뒤 다시 열어 보고, 계속 안 되면 클로드에게 상황을 그대로 말해 확인을 부탁하세요.
안내에 나온 메뉴가 화면에 없어요
화면에 보이는 것을 말로 설명하거나 캡처해 클로드에게 보여 주세요. 메뉴는 바뀔 수 있습니다.
개인정보가 올라간 것 같아요
바로 클로드에게 알리고, 어떻게 내릴지 안내받으세요.

발표자 사례

발표자도 손목 컨트롤러의 웹 시뮬레이터, USB 설치 페이지, 따라 하기 안내서를 이렇게 GitHub Pages에 올려 링크 하나로 나누었습니다. 앱처럼 설치해서 쓰는 방식(PWA)도 함께 적용했습니다.
